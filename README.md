# 🔮 魔法占卜球 (Magic Crystal Ball)

一个基于 **Vite + Three.js** 的炫酷实时流体模拟网页。画面中央悬浮着一颗高透光率的水晶球，球内数千个五彩金属亮片在神秘流场中缓缓流转。按住鼠标在球体表面拖拽，即可唤醒流体的魔力，产生漩涡与推力。

![预览](test-screenshot.png)

## ✨ 特性

- **真实玻璃质感** — `MeshPhysicalMaterial` 高透光率 + 折射 + 体积吸收
- **实时流体模拟** — 基于 3D Curl-Noise 的伪流体速度场，性能极佳
- **GPU 级粒子系统** — 6000 个 `InstancedMesh` 金属亮片，独立配色
- **鼠标交互** — 球面拖拽产生推力与漩涡，亮片跟随流场翻滚飞舞
- **魔法氛围** — Bloom 光晕、脉动幽蓝光源、菲涅尔边缘光
- **物理沉淀** — 水流静止时，亮片在重力与阻力下缓缓沉落球底

## 🚀 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

浏览器访问 `http://localhost:5173`，按住鼠标在球体上拖拽即可交互。

## 🎮 交互说明

| 操作 | 效果 |
|------|------|
| 鼠标按住 + 在球面拖拽 | 在球内产生流体推力与漩涡 |
| 松手 | 流场渐缓，亮片在重力下沉淀 |
| 触摸拖拽 (移动端) | 同鼠标交互 |
